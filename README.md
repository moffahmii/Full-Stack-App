# Inventory Overview Application

A responsive, full-stack web application built to manage and display inventory items using a modern web architecture. The project focuses on delivering a clean, minimalist user interface while ensuring fast data retrieval and high performance.

## Features
- Minimalist and responsive user interface
- Server-Side Rendering (SSR) for optimal performance
- Direct database querying via Server Components
- RESTful API endpoint for data retrieval
- Fully typed architecture for better maintainability

## Tech Stack
- Framework: Next.js (App Router)
- Language: TypeScript
- Styling: Tailwind CSS
- ORM: Prisma
- Database: MongoDB
- Deployment: Vercel
